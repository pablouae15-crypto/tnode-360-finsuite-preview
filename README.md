# T-Node 360 FinSuite — public visual preview

This repository contains only the generated static demo website with fictional example data. Accounting backend source, database code and architecture remain in a separate private repository.

This preview does not authenticate users, process payments or save live accounting records. Example changes reset on reload.

Repository owner: select Settings → Pages → GitHub Actions, then run the Publish visual preview workflow. The successful deploy job provides the website URL.
